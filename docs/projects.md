## Ragent — 检索增强生成问答系统

**技术栈**：Spring Boot · Milvus · Redis · PostgreSQL · LangChain4j

一个面向私有文档集的 RAG 问答系统。用户上传文档后，系统自动完成切片、向量化与入库；提问时进行混合召回，再把相关片段拼接到上下文交给大模型生成答案，并支持多轮会话。

**核心设计**

| 模块 | 选型 | 取舍理由 |
| --- | --- | --- |
| 向量检索 | Milvus | 支持 IVF_FLAT / HNSW 等多种索引，亿级向量下召回延迟可控，社区活跃 |
| 会话与缓存 | Redis | 存多轮对话历史，并对高频问题的检索结果做缓存，降低重复 LLM 调用成本 |
| 业务数据 | PostgreSQL | 文档元数据、用户权限与会话的关系型存储，与向量库职责分离 |
| 应用框架 | Spring Boot | 团队协作与后续上线的工程化成本低，便于接入监控与鉴权 |

**技术要点**

- 文档切片策略：按语义段落 + 固定窗口重叠切分，避免长文档跨段语义断裂
- 混合召回：向量召回与 BM25 关键词召回融合，缓解纯向量检索对专有名词不敏感的问题
- 缓存层：对同一 query 的 embedding 与召回结果做两级缓存，命中率高时可显著降低响应耗时
